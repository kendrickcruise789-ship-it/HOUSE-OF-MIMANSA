# HOUSE-OF-MIMANSA

Clothing brand for a Jaipur based company — handcrafted hand-block printed apparel.

## Homepage

The site is a static front end. Open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server 8080
# then visit http://localhost:8080
```

## Structure

- `index.html` — homepage markup (announcement bar, header, hero, footer, mobile nav drawer)
- `css/style.css` — theme and layout (colour scheme: Warm Ivory `#F8F5EF`, Charcoal `#33302E`, Soft Beige `#E9DED4`, Muted Rose `#885365`)
- `js/main.js` — mobile navigation drawer toggle
- `assets/` — imagery

Fonts: Cormorant Garamond (serif) + Jost (sans) via Google Fonts.
